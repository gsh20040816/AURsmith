# AURsmith v0.1.0-alpha.1 发布说明

这是面向单用户、1～2 台 Arch Linux 客户端的首个可部署预发布版本，不是功能全部完成的正式版。

## 使用定位

该版本适合在受信任局域网中试部署：Controller、Builder、Publisher、Archiver 全部以独立 Docker Compose Stack 运行，客户端使用标准 pacman 仓库协议。部署者仍需自行准备 KVM、SSH/GPG/Controller 密钥、内部 DNS/HTTPS 和至少一个构建 Profile。

## 发布门禁

发布候选满足以下条件：

- `bash scripts/test-all.sh` 通过；
- 需求总账和验收矩阵已更新；
- 工作树无未提交修改；
- 使用 annotated Git tag `v0.1.0-alpha.1` 固定源码；
- 不在没有 Git remote 的情况下声称已经推送或创建托管平台 Release。

## 部署前必须人工确认

1. 离线备份 Controller、GPG、SSH、内部 CA 私钥和管理员恢复材料。
2. 核对 Builder `/dev/kvm`、Profile 摘要和构建镜像源。
3. 核对 Publisher 仓库 GPG 指纹、稳定仓库地址和客户端仓库排序。
4. 运行 Web Doctor，确认三个低成本 Runner、一个高成本 Runner、AUR 和 source proxy。
5. 若配置真实模型 API key，先用非关键包验证 Codex/Claude provider；Doctor 本身不会调用模型。
6. 抽查归档 Release 的 `evidence/<attempt-id>/`，确认 Profile、Source 和 Build 三个证据归档均被 ArchiveReceipt 覆盖。

## 回滚

服务端可切换到已有签名 Release。客户端不会自动降级，必须使用 Web 生成的归档 `pacman -U` 命令。控制面恢复应停机执行，并保留恢复前数据库副本。
